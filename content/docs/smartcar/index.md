# 铁人战队 · 智能车文档

欢迎来到铁人战队智能车培训文档中心。我们围绕**全国大学生智能汽车竞赛**，构建了一套从入门到进阶的系统化学习路径。

## 培训体系概览

本套文档分为三大模块，覆盖智能车开发所需的全部核心能力：

- **序章** — 了解提问技巧、学习路线图、硬件/软件入门指引
- **初级硬件** — 从元器件认知到 PCB 设计，带你完成第一块电路板
- **初级软件** — 开发板选型、文档阅读方法、环境搭建与版本控制

## 学习建议

如果你是初次接触智能车，建议按照左侧导航栏的顺序依次阅读。每一章节都包含理论知识、实操示例和常见问题，帮助你循序渐进地掌握各项技能。

遇到问题？先查阅文档中的常见问题章节，也可以在团队交流群中与队友讨论。
